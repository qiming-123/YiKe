# 译刻 · VS Code 选区适配 1.1.0

配合 Windows 译刻 1.7.0 及以后版本。设置 → 外观与行为 → 安装 / 更新 VS Code 适配；更新后重新打开 VS Code 窗口。

编辑区：鼠标拖选或双击，译刻按本次手势读取当前编辑器选区。不需要读屏模式，不更改文档、设置或剪贴板。最多 32 个范围、2,000 个 Unicode 码点；编辑、键盘选区、切换窗口和过期手势不会返回旧文本。

Terminal：在终端选中文字，按 **Ctrl+Alt+Y**，执行“复制并翻译 / 解释终端选区”。这一步明确使用 VS Code 原生“复制选区”，会把选中文字放进剪贴板；不会还原原剪贴板或清除系统剪贴板历史。没有选区时不会读取旧剪贴板。只在 Code 前台且译刻未暂停、未固定、未排除 Code 时生效。若快捷键被其他应用占用，可用终端原生复制后通过译刻托盘“粘贴文本翻译”。

终端入口不执行命令，不向终端发送输入，不读取完整输出、滚屏缓存、命令历史或环境。复制之后由译刻校验新的剪贴板序列、所属 Code 进程及当前窗口，再限长读取。原始选区不会写入日志。选区按译刻当前选择的本地或在线服务翻译；选择在线服务时选区会发送到配置的服务。

普通 VS Code 扩展尚无稳定的终端选区读取 API，所以终端不能承诺与编辑区一样仅拖选即弹出。未启用 proposed API、读屏模式或调试端口。终端鼠标事件模式下，Windows 可按住 Alt 拖选；如果终端程序接管鼠标，先确认文本确实高亮。

内置命令资料显示适用环境、作用、语法、常用选项、本次参数、示例、效果和必要的修改影响。PowerShell、CMD、Bash 的同名命令可能不同，终端本身不能决定可用命令。示例仅供阅读，不会执行。

本机 UI 扩展宿主和 Windows 桌面版为支持目标；网页版不支持。多窗口按当前 Code 进程树认证命名管道，不读取其他窗口的编辑器选区。SSH / WSL 等终端仍通过本地终端原生复制，翻译器不会连接远程主机；版本差异需以实际环境为准。自定义编辑器、PDF、网页预览不属于此适配接口。

卸载扩展 yike-local.yike-selection 即可移除适配；卸载译刻不会自动卸载 VS Code 扩展。
