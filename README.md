## 版本概览

首次正式发行。日、韩、法、德、西五种研习词典均可独立下载。安装包和主程序未签名。

手动翻译可选择源语言与目标语言。节能引擎固定英译简中，其他方向可在设置选择通用多语模型或在线服务。开启英语研习后，在单词浮窗点击「收藏单词」，从主界面「单词收藏本」复习、删除、导出或单独设置收藏目录。仅保存主动收藏的词头，释义从内置词库读取。「数据与迁移 → 更改数据目录」切换设置和默认收藏本的位置，原文件保留为副本。

Windows 划词翻译工具。默认只翻译，不保存历史；设置和密钥沿用旧版。

## 使用

运行 `YiKe-Setup-2.0.0-win-x64.exe` 安装或覆盖升级。安装包自带免费英汉词库、英译中节能引擎和隔离的运行组件，不需要自行安装 Python、.NET、显卡驱动或申请词典 API。请保留安装目录中的 `translation-runtime`，不要只移动 EXE。

- 划词响应可选自动翻译，或先显示“译”小图标、点击后才翻译；图标阶段不会启动翻译模型或发送原文。
- WPS PDF：用“选择”工具划选文字即可取词，默认直接翻译；开启图标模式时点击新棱形“译”徽标翻译。直接接口不可用时自动复制取词，尽量恢复原剪贴板，不覆盖其他应用的新复制。仍可手动按 Ctrl+C 兼容取词。扫描图片 PDF 仍需要先识别文字。PDF 整理默认开启，保守合并断行和词库确认的断词，保留段落、代码和不确定的连字符；浮窗“原文”保留复制前文本。
- 浮窗可临时开关“技术释义”“英语研习”，设置页可保存默认开关。两项独立，默认关闭。技术释义提供本地计算机术语、命令与示例；英语研习提供词库音标、多释义、英文定义及手动朗读单词，不朗读整句、不分析语法。朗读使用 Windows 英语语音。
- 双击译刻打开主界面，左侧可直接进入手动翻译或使用指南。首次显示可跳过的教程。在「外观与行为 → 视觉风格」预览深色赛博朋克与浅色 Y2K 银晶，点击「保存设置」记住选择。

## 翻译服务

| 选择 | 适用范围 | 条件 |
| --- | --- | --- |
| 本地·英译中节能引擎 | 英文单词和句子→简体中文 | 内置 ECDICT、OPUS-MT INT8；按次启动，翻译后释放 |
| 本地·通用多语模型 | 其他语言方向、可选模型扩展说明 | 保留已有 Qwen；需要更多空闲内存 |
| 在线·DeepL | 传统翻译 API | 自己申请 Key，可选免费额度或付费计划；无付费词典 |
| 在线·OpenAI 兼容接口 | 自选模型翻译及可选术语补充 | 自己的兼容地址、Key、模型，沿用多组配置 |

升级首次运行将旧版“所有文字都附加计算机说明”调整为默认纯翻译；目标为简体中文且组件齐全时默认采用节能引擎。原有在线/离线选择、API 配置、加密密钥和 Qwen 文件保留。其他方向可在设置切回通用多语模型。不会在本地失败时自动转发到在线服务，也不会自动购买服务或下载模型。

在线设置选择 DeepL 预设后填写自己的 Key；免费账户使用 `https://api-free.deepl.com/v2`，专业账户使用 `https://api.deepl.com/v2`。DeepL 使用专用协议，无需模型列表。兼容 AI 服务仍按原有流程配置与测试。连接测试由用户主动发起，可能计入服务用量；未使用用户真实 Key 做付费验收。

## 内存与限制

本机（约16 GB、20逻辑处理器）合成句子测试中，节能工作进程峰值工作集约129 MiB、私有内存约150 MiB；这不包含 WPF 主程序，也不代表低空闲内存压力测试。旧 Qwen 轻量模型同类测试约1166/885 MiB，调整后约1052/771 MiB。详情见 [内存报告](docs/MEMORY_1.8.0.md)。翻译仍有多义词和措辞错误，不能保证所有句子的准确率。

节能引擎仅英译简中，不支持中译外或繁体目标；单行最多512个模型 token，应用选区上限2000个Unicode码点，超限报错而不静默截断。通用轻量模型需约1.25 GiB空闲内存，标准模型约5 GiB；单独保留一个模型时仍需满足门槛。详细 [本地引擎说明](docs/LOCAL_MODEL.md)。

已发布的 2.0.0 安装包要求 Windows 11 x64（内部版本 22631 或更新）。主线源码中的安装器最低要求为 Windows 10 22H2 x64（内部版本 19045）。`YiKe-Portable-2.0.0-win-x64.zip` 是完整便携包，另含旧通用双模型，体积仍较大。首次启动不联网下载；便携模式会将配置保存到自己的 data 目录。不要把带个人配置的便携目录公开分发。

当前构建未签名：交接中没有原 opens 签名私钥，未创建替代证书或修改系统信任。当前验证范围见 [测试报告](docs/TEST_REPORT.md)，历史报告明确保留版本号。

## 源码构建

固定 .NET SDK 10.0.402、Inno Setup 7.1.0，另需 Node.js 运行词库构建/适配器测试。

```powershell
./scripts/bootstrap-tools.ps1
./scripts/bootstrap-dictionary.ps1
./scripts/bootstrap-local.ps1
./scripts/bootstrap-nmt.ps1
./scripts/build-release.ps1 -Version 2.0.0
```

运行组件不写入源码包；来源版本、下载地址和SHA固定在 `assets/nmt-source-lock.json`、`local-model.lock.json`，运行文件身份在 `assets/nmt-package.json`、`assets/local-package.json`。发布脚本执行自动测试、真实本地翻译、产物哈希和来源一致性检查。可选签名需提供自己的签名脚本与证书；不复用未知私钥。


自动复制会临时使用剪贴板。支持恢复常用文本、HTML、RTF、图片及文件列表；特殊私有格式或可恢复内容总量超过64 MiB时保留手动 Ctrl+C 路径。恢复时在剪贴板锁内核对序列号，不覆盖期间的新复制。
