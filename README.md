# 译刻 YiKe

选中文字，松开鼠标，在附近读译文。可选择本地离线模型或在线 API。

**当前版本 1.7.8 增加 WPS PDF 划选后按 Ctrl+C 翻译。** 同时保留多组在线 API，各自保存地址、加密密钥和模型，可直接切换。 保留未选文字时安静不弹窗、所有选区的计算机说明和安装时选择本地模型，使用 opens 自签名。小型安装器包含词库与引擎，内置应用、CPU 引擎、.NET 和所需 C++ DLL；模型根据安装选择单独下载，不要求 Python、Node.js、Ollama、显卡驱动或额外配置。完整离线便携包仍内置两个模型。

签名身份 **opens** 属于自签名，Windows 默认不信任；私钥不随包分发。详情见 [签名说明](docs/SIGNING.md)，实际检查见 [测试报告](docs/TEST_REPORT.md)。

## 开始使用

运行 `YiKe-Setup-1.7.8-win-x64.exe`。选择安装目录后，向导显示物理内存、当前空闲内存和逻辑处理器数量，并推荐合适的模型：

| 安装选项 | 模型下载量 | 使用方式 |
| --- | --- | --- |
| 本次不下载 | 0 | 可先安装程序，稍后补装模型或自行配置在线 API；升级保留已有模型和选择 |
| 轻量 Qwen3 0.6B Q4_0 | 约 429 MB | 约 8 GB 内存、4 个逻辑处理器起；优先响应速度 |
| 标准 Qwen3 1.7B Q4_K_M | 约 1.28 GB | 约 16 GB 内存、8 个逻辑处理器起；运行时需至少 5 GB 空闲内存 |
| 两种都下载 | 约 1.71 GB | 使用时根据电脑与当前可用内存自动切换 |

安装器会预选推荐模型；低于基本硬件门槛的选项不可选。升级默认“本次不下载”，避免擅自增加模型。已有且 SHA-256 校验通过的所选模型直接复用；缺失或损坏时下载补齐。下载需要联网，文件固定到模型仓库的指定提交并核对 SHA-256；失败或取消会停在安装前，可重试或返回模型页选择不下载。下载时系统临时目录和安装目录都需要足够空间。

安装完成后，已下载的模型可直接离线翻译，无需地址、API Key 或环境配置；第一次加载时稍候。只选轻量模型时，程序会使用轻量模型，即使这台电脑也能运行标准模型。未安装模型时会明确提示补装方式，打开设置，不会自动下载或把原文转发给在线服务。更换 / 补充模型可重新运行同一版本安装包，原有设置和密钥保留。

完全离线安装：运行 `YiKe-Offline-Setup-1.7.8-win-x64.exe`（约 1.78 GB），安装时从包内选择轻量、标准或两种模型，按电脑情况推荐，无需另行下载。也可完整解压 `YiKe-Portable-1.7.8-win-x64.zip`（约 1.77 GB），双击 `YiKe.exe`；不要只移动 EXE。两个完整包均内置模型和运行组件，不在首次启动时下载。完整环境隔离的历史验收来自 1.2.0；本轮检查和范围见 [测试报告](docs/TEST_REPORT.md)。

支持 Windows 11 23H2（build 22631）及更新版本的 x64 系统，当前在 build 26300 实测；不提供 ARM64。全部本地模型至少需要约 8 GB 内存、4 个逻辑处理器、SSE4.2 和至少 2.5 GB 当前空闲内存；低于门槛时不加载模型。两种都安装时，约 16 GB 以上 / 8 个逻辑处理器且空闲内存达到 5 GB 才选择标准模型。详情见 [硬件策略](docs/LOCAL_MODEL.md)。

1. 运行安装器并选择模型；桌面快捷方式和开机启动首次默认不勾选。
2. 默认目标语言为简体中文；设置中有 22 项语言预设和自定义输入。跳过模型的新安装需选择在线 API 并填写自己的服务信息后才能在线翻译。
3. 在支持选区接口的应用中拖动划选或双击单词。释放后防抖 80 ms 再读取真实选区；辅助进程会提前启动，最多在 2.2 秒内对同一次手势重查 6 次，不读取剪贴板。未确认文字前不显示读取浮窗；确认选中文字后显示翻译进度；相同文字重复划选复用未完成请求，显式“重试”才强制重新请求。上限为 2,000 个 Unicode 码点，超限不截断、不发送。
4. 浮窗可查看原文、复制译文、主动重试、固定或关闭。自动划词不修改剪贴板；主动“复制译文”和终端“复制并翻译”会更新剪贴板。

**可选在线模式：**在设置中将翻译方式改为“在线 API”，填写 HTTPS API 根地址和自己的 API Key。模型检测在输入停顿约 0.8 秒后读取当前服务的模型列表，可点击“刷新模型”重新获取。列表只表示账户可见的模型，不保证每个模型支持文本翻译；请选用支持 Chat Completions 的模型，可主动“测试连接”确认。不支持列表接口、权限不足或网络失败时仍可手动填写，不会覆盖当前模型。目标语言提供 22 项预设及自定义输入，升级保留已有语言选择。接口格式依据 [OpenAI Docs](https://developers.openai.com/api/reference/resources/models/methods/list)。

**保存多组 API：**在“翻译服务 → 在线 API 配置”点击“新增 API”，为每组填写名称、地址、密钥和模型；最多保存 32 组，同一地址可保存多个账号。下拉列表切换编辑配置，窗口内尚未保存的内容会保留；点击“保存设置”后统一保存，并使用当前选择的 API。重启记住选择。高级超时和指令角色也按配置分别保存，语言与外观仍共用。删除配置在保存后生效，仅清理对应密钥，至少保留一组。旧版本的单 API 自动成为“默认 API”，不用重填密钥。只会向当前 API 发起翻译，不会并行调用其他配置或自动切换服务。

**WPS 文字：**已打开的 DOCX / RTF 普通连续文字可直接划词，无需安装适配插件或修改 WPS 设置。译刻只连接已有的 WPS 文字实例，核对当前窗口、文档、选区范围和位置，再读取所选文字；兼容 WPS 自身的悬浮工具栏，不自动操作剪贴板。跨段落、汉字和表情已实测。列选择、整表行列、图形、演示 / 表格以及部分不开放接口的版本不属于本版已验证范围。

**WPS PDF：**先选择阅读器的“选择”工具，拖动划选正文，再于 15 秒内按 **Ctrl+C**。直接选区接口不可用时，译刻识别本次由同一 WPS PDF 窗口或其 PDF 子进程新复制的文字并翻译；未产生新复制结果、切换窗口、普通点击或文件拖放不会触发。此入口默认开启，可在“设置 → 外观与行为 → WPS PDF：划选后按 Ctrl+C 翻译”关闭。译刻不主动按复制键或改写剪贴板；Ctrl+C 本身会复制你所选文字。暂停、固定及排除 WPS 时不读取。已在本机 WPS 12.1.0.28488 文本 PDF 实测；扫描图片、禁止复制的 PDF 需先取得可复制文字，不提供 OCR 或解除限制。

**VS Code：**安装译刻时勾选“VS Code 编辑器划词适配”，或在译刻“设置 → 外观与行为”点击“安装 / 更新 VS Code 适配”。无需开启读屏模式或修改编辑器设置；如当前窗口尚未加载新扩展，重启 VS Code。适配扩展使用本机管道，仅应译刻的本次鼠标划词请求读取当前焦点编辑器选区；暂停、排除 `Code` 和固定浮窗继续生效。终端使用下方 Ctrl+Alt+Y 复制入口；网页版、自定义编辑器和 PDF 不属于此适配已验收范围。

本地模式无需密钥，也不会自动转发到在线服务。在线模式没有可用密钥时不发请求，会显示配置提示。保存与测试连接相互独立；“测试连接”只提交固定的 `Hello, world!`，可能由服务商计费。普通托盘启动不测试在线连接；仅在选择在线模式后，打开设置、填写或更改地址与密钥才会自动读取模型列表，不发送选区或翻译样例。网络错误不会删除密钥，也不会自动换服务商或无限重试。

本地模式下，简体中文目标的普通词优先使用内置的约 76 万条英汉词库和常用词修订，无模型也可查词；未收录词走独立的词汇翻译提示。开启解释时，普通词也显示计算机用法；标准本地模型或在线服务可在译文完成后单独补充，每次最多增加一次说明请求（在线可能计费），30 秒内未完成则保留离线说明。本地异常结果最多补做一次纯翻译，在线服务不会自动重发。轻量模型的句子翻译仍可能遗漏或误译，查词修复不代表所有长句语义正确。单选多义词时词典列出常见译法；选中完整句子可获得语境翻译。

## 计算机术语

**VS Code Terminal：**更新适配并重新打开 VS Code 后，在终端选中文字，按 **Ctrl+Alt+Y** 复制并翻译 / 解释（会更新剪贴板）。终端选区接口与编辑器不同，因此使用显式快捷入口；不启用读屏模式或 proposed API。没有新复制结果时不读取旧剪贴板。

默认开启计算机术语解释。另有 70 种命令 / 子命令的详细用法（Linux、PowerShell、CMD、Git、Python、npm、Docker），逐项说明语法、常用参数、选中参数、示例及效果；未收录参数明确标记。内置 219 组术语，每组附简短示例和效果说明，覆盖 Linux 命令与参数、系统、网络、数据库、安全、硬件、算法、AI 及编程语言用途，离线可用。已有专业词解释保持原流程；任意其他选区也显示离线用法或资料范围，普通词可在译文完成后单独补充模型说明。轻量或无模型时使用离线说明；模型说明可能有误并增加生成量。解释与复制译文分开，两个开关可在设置 → 翻译服务调整。每次词库最多显示 4 组，不保证覆盖或正确解释所有术语。详见 [使用与范围](docs/PROGRAMMING_TERMS.md)。

## 日常操作

托盘右键可暂停/恢复、打开设置、粘贴文本翻译和退出。排除应用按进程名填写，例如 `Code`、`msedge`，每行一个。普通点击和窗口拖动不触发翻译；未提供可读取选区接口的应用可手动打开粘贴入口。密码控件会跳过，但不能自动识别所有敏感内容。

固定仅保留一个浮窗：固定后当前请求可继续完成，不接收新自动划词；解除固定后等待下一次划词。关闭或暂停会取消并使后续结果失效。在线模式的取消不能保证服务商不计费。本版没有全局 Esc、OCR、扫描 PDF、历史、浏览器扩展或自动更新。

浮窗自动出现不激活原窗口，最多显示一张卡片。多屏位置根据显示器工作区限制；实际多屏、负坐标和高 DPI 场景尚需补验，详见报告。深浅主题可在设置中选择，跟随系统为默认；系统偏好变化会自动刷新；窗口使用进程内软件渲染以改善远程桌面和不同显卡驱动下的兼容性。

## 凭据和数据

安装版：`%LOCALAPPDATA%\YiKe\settings.json` 保存偏好及所有 API 的非密钥信息，`credentials\*.bin` 分别保存 DPAPI CurrentUser 密文。密钥绑定服务 ID 及规范化端点，不绑定 EXE 路径。未填新值会保留原绑定密钥；更换地址后必须填写该地址的密钥才能请求，不会借用其他地址或配置的密钥。认证失败不清空旧凭据。普通导出包含所有配置但不含密钥；加密迁移包一次迁移全部已保存的 API 密钥。

密钥在同一 Windows 用户下重启后自动读取。安装目录不会包含个人密钥，覆盖升级不会部署示例配置。密文不能直接跨 Windows 账户或跨电脑使用。删除当前服务密钥：托盘 → 设置 → 数据与迁移 → 删除当前服务的本机密钥。卸载时也可主动勾选删除设置与所有本工具保存的密钥，默认保留。

便携版：解压 `YiKe-Portable-1.7.8-win-x64.zip`，运行 `YiKe.exe`。随包的 `portable.flag` 明确启用便携模式；偏好写入旁边的 `data/settings.json`，并保存用户目录副本。相同配置 ID 取较新修订，不同 ID 优先便携配置。便携目录不可写时提示用户目录保存位置；如果该目录仍有另一配置 ID，会明确提示下次启动仍优先加载旧便携配置。完整离线版必须保留 local-runtime/ 和 licenses/ 文件夹；只移动 EXE 无法使用本地翻译。随完整目录移动仍读取便携配置。原生运行时可能解压到用户临时目录，请保证临时目录可写与磁盘空间充足。

普通配置导出为 JSON，**不含密钥**。新电脑导入后，本地模式直接使用；在线模式需填写密钥。“加密迁移包”使用 PBKDF2-SHA256（600,000 次）、随机盐、AES-256-GCM 和随机 nonce，包含配置及密钥，需要 10–1,024 字符密码；新电脑导入后密钥重新保存为本机 DPAPI 凭据，此后日常使用不再输入迁移密码。错误密码或篡改包在写配置前失败。不要把迁移包或密码放进普通发布 ZIP。

本地模式由已安装的 Qwen3 0.6B Q4_0 或 1.7B Q4_K_M 处理，遵循安装选择及硬件门槛，文本经本机受保护的回环连接发送给应用自己的引擎，不发往互联网，不开启网页界面，不保存生成日志或磁盘提示缓存；轻量 / 标准档分别闲置约 5 / 15 分钟后释放模型内存，内存过低时提前释放，退出时停止引擎。小型模型适合日常短句，复杂句及部分语言可能省略内容，效果边界见测试报告。

在线模式的请求只包含本次选区和必要翻译参数，不发送窗口标题、截图或历史。原文、译文、请求体与鉴权不写入日志，无遥测。服务商的留存政策由其自行决定。输出始终为纯文本，不执行 HTML、脚本或命令。

## 升级、卸载和恢复

安装 EXE 使用固定 AppId，支持同版重装和覆盖升级，拒绝已知较新版本上的降级。升级通过应用自己的退出命令关闭译刻及取词进程；无法关闭时提示，不终止其他应用。自启动由当前用户 Run 注册项控制，安装器与设置使用同一个项，升级读取实际设置。

卸载默认删除应用、快捷方式、自启动项及卸载信息，保留用户数据。交互卸载的“同时删除设置和已保存的 API 密钥”默认不勾选，选择后仅删除已知 settings.json 与 credentials/*.bin，不删除手动导出的文件。静默卸载始终保留数据。失败或取消后不要清理用户数据；如程序文件损坏，重新运行同版安装器恢复。未实测的故障场景不承诺自动回滚。

## 常见问题

- 无浮窗：确认未暂停、应用未排除，确实拖动划选或双击；数据页可查看不含文本的取词状态。浏览器、PDF、Word 等必须分别实测，权限更高的程序可能无法读取。不要为普通使用提升本工具权限。
- 认证、额度、模型错误：核对该端点的 Key、模型权限和服务商余额。保存状态不等于服务可用。
- 流式不兼容：设置关闭流式后主动重试；程序不会静默重发可能已计费的请求。首译文默认 30 秒、总请求 90 秒，可调整。
- 密钥无法解密：更换 Windows 用户后需输入密钥或导入加密迁移包；旧文件保留。
- 单文件启动失败：检查临时目录和磁盘，完整重新解压/安装。当前 opens 自签名不属于系统默认信任的 CA 身份，仍可能出现 Windows 安全提示；不需要关闭安全功能。

## 构建

PowerShell 7 和 Node.js 20+（仅扩展测试使用，用户运行译刻无需 Node.js），在本目录执行：

```powershell
./scripts/bootstrap-tools.ps1
./scripts/bootstrap-local.ps1
./scripts/build-release.ps1
```

工具固定为 .NET SDK 10.0.402 / Desktop Runtime 10.0.13 / Inno Setup 7.1.0，URL 与校验值在 `build-tools.json`。脚本安装编译器到项目 `.tools/inno`（会注册该当前用户构建工具），不修改系统 PATH。也可以传 `-Dotnet`、`-Iscc` 指向预备好的相同版本。首次恢复依赖需要网络；最终安装包离线含运行时。NuGet lock 文件纳入源码。

发布脚本：锁定恢复 → 构建 → 运行核心与界面回归及布局夹具 → 单文件自包含 Release → Inno Setup → 同构建便携 ZIP → 签名状态/体积清单 → SHA-256、源码逐文件及 ZIP 内容核验。测试入口为控制台可执行测试项目，无第三方测试框架；测试失败将阻止发布。`--visual` 生成真实 WPF 控件的布局夹具，标为非 API 结果。`--install-data` 和 `--desktop-data` 仅用于安装/桌面验收的合成数据，普通发布包不含此测试程序。

`scripts/test-installer.ps1` 默认仍用于历史 1.0.0 → 1.0.1 的隔离验收；传版本参数可针对新包验收。历史流程覆盖 的运行中升级、同版重装、文件占用失败与恢复、自启动显式任务和默认卸载。需要旧版实际安装文件（可传 `-PreviousSetup`）；不会用新源码伪造历史版本。先在本目录运行发布脚本，之后仅在没有既存译刻用户数据的环境执行安装测试，它拒绝覆盖现有配置。当前用户的测试安装应用和对应注册项会随此测试创建、删除；报告标明实际执行情况。`build-release.ps1 -PackageOnly` 用构建记录核对源码输入、应用及安装器的哈希，仅允许在同一已验证构建上更新资料和 ZIP。可执行输入变化必须完整重建；`builtUtc` 与 `packagedUtc` 分别记录构建和重新打包时间。

签名：可给 `build-release.ps1 -SignScript <安全脚本绝对路径>`，该脚本接收待签文件路径，调用配置好的证书和可信 RFC3161 时间戳签名工具。应用、安装 EXE、安装器生成的卸载器均预留签名步骤；构建检查实际签名。证书、密码和私钥不进入仓库。没有证书时继续生成 `NotSigned` 构建，不虚构已验证发布者。商业分发前需核对 Inno Setup 商业许可。

协议实现依据 [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[SSE 事件](https://developers.openai.com/api/reference/resources/chat/subresources/completions/streaming-events)、[Microsoft TextPattern.GetSelection](https://learn.microsoft.com/en-us/dotnet/api/system.windows.automation.textpattern.getselection?view=windowsdesktop-10.0)。版本与实现限制以本项目测试报告为准。

离线包的引擎、模型、微软 DLL 下载来源与摘要在 local-model.lock.json，完整运行文件清单在 assets/local-package.json。bootstrap-local.ps1 仅供源码构建者使用；成品包运行时不下载模型或安装系统组件。更多说明见 [本地模式](docs/LOCAL_MODEL.md)。

桌面图标拖动、框选和双击不作为划词。文件资源管理器的项目选择与真正文本选择分别处理；重命名、地址 / 搜索输入框和可读取预览文本保留取词。非文本 Shell 区域读取失败不会弹错误卡片，可在设置查看不含原文的诊断。

响应提示：第一段有效流式译文到达即显示，后续最多按约 80 ms 更新。划选时旧浮窗立即隐藏，已发送请求短暂保留，以便同文复用；新文字确认后取消旧请求，点击未形成选区时按系统双击时间等待（上限 1 秒）后取消。显式关闭、暂停、排除应用及读取失败仍取消。未取得文字的自动操作保持安静，原因可在设置中查看诊断；手动粘贴与终端快捷键的显式操作仍保留错误提示。

自动浮窗条件：必须读取到真实非空文字选区，或确认选区超出长度上限。普通点击、空选区、暂不支持、超时、拒绝读取或来源失效不会弹取词错误。鼠标拖动阈值为按窗口 DPI 缩放的 6 DIP；极短单字可双击选择。双击按两次鼠标按下时间判断，避免长按后的普通单击误判。
