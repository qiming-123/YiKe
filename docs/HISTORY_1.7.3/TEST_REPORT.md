# 译刻 1.7.3 · 任意词的计算机说明验收

2026-10-24（Asia/Shanghai）。本轮按用户要求，将计算机说明扩展至所有有效选区，保留独立译文、离线查词、原专业资料及用例。此前版本的原因分析与资料见 HISTORY_1.7.2/TEST_REPORT.md。

## 最终行为

解释总开关开启时，所有词或选区都有计算机说明。已知专业词保留原 219 组词库与 70 种命令 / 子命令用法；how、unmark、square / squares 等另有离线软件、文档、网格与状态示例。ECDICT 有计算机义项时列出该义项；未确认的选区明确资料范围，并给出通用字符串场景，不把普通词伪装成关键字或命令。

普通选区的翻译先完成，再由标准本地模型或在线服务补充说明，最多一个额外说明请求、独立预算最多 30 秒。译文可立即复制。说明异常不重译、不循环重试、不把译文改为失败；无效或空说明保留离线内容。已完成的模型说明可缓存，开关关闭时隐藏；取消和换选区不会显示过期结果。轻量或无模型时不为说明启动模型或自动切到在线。固定连接测试明确关闭说明请求，只翻译固定样例。

在线服务的独立说明请求可能计费。说明输入仍只有本次选区和固定任务指令，不读取上下文或记录原文。示例为纯文本，不执行。模型说明有长度上限、固定格式检查、来源标注；这些检查不保证知识和语义准确。

## 模型质量与范围

标准档任意词检查使用真实 1.7B 模型；普通词先由内置词库完成译文，再发生一次独立说明。实际完成时间分别记录 firstTranslationCompleteMs 和 totalMs。轻量档使用硬件快照，真实选择轻量策略，但这四次查词 / 说明不启动引擎，全部来自离线资料。低配物理电脑未实测。

格式检查要求中文“说明、示例、效果”且不接受省略占位，失败直接保留离线说明。但语义仍会出错，例如本次 banana 的模型例子将 Python 变量赋值的效果说成“存储并显示”，实际赋值本身不会打印。该原始输出保留，没有宣称模型解释全部正确。

轻量 0.6B 整句仍有两项内容失败：取消标记句误译反向动作，并把 mine 译作矿；棋盘句将 mines 译成炸弹。原文、完整输出和 knownLightSentenceContentFailures 保留在 WORD_LIVE_LIGHT.json。非空、目标语言及请求完成不等于语义通过。词库多义项和未知资料同样需结合语境，不读取外部页面，也不假定具体软件。

## 安装与交付

本机安装使用正式小安装器，复用已有标准模型，没有下载新模型或覆盖用户偏好。完整离线单 EXE 内置轻量和标准模型、CPU 引擎、自包含 .NET 与 C++ DLL；安装时可选择模型并按硬件推荐。

离线安装验收使用与正式包同一生成 Inno 源码、独立的 InstallerSmoke 注册身份，覆盖不装模型仍可查词、无效参数、轻量 / 标准 / 双模型、损坏修复、散列复用、偏好保留、卸载器签名、真实本地推理与正式用户状态不变。未关闭网卡、改防火墙，也未在另一台全新 Windows 上完成 GUI 安装；离线能力依据无模型下载代码、包内载荷及实际本地推理核验。

opens 自签名与 SHA-256 / RFC3161 时间戳保留，系统默认信任链不受信任，未安装信任根或分发私钥。最终文件长度、散列、生成源码和可执行输入身份见 dist 的 BUILD-MANIFEST.json、OFFLINE-BUILD-MANIFEST-1.7.3.json 与校验清单。资料归档使用 PackageOnly 复核同一已验证可执行输入；文档整理不会替换已签名应用。
