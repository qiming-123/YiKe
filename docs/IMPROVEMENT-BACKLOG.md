# 译刻 YiKe 改进清单

三轮审阅以 `main` 的 `b86c71e` 为基线。以下优先级是开发排期建议。选题前先核对当前实现和用户指令，已解决的条目按实际结果更新。除注明的静态或独立验证外，验收场景尚待运行。

每次落实改进后，在同一批变更中更新对应条目，记录完成或部分完成的状态、实际改动和验证结果。尚未验证的内容标为待验证。清单外的改进落实后补录。

## 优先考虑

| 方向 | 改进与验收 |
| --- | --- |
| 保留手动翻译草稿 | 切换引擎并保存设置后，保留原文、选区和滚动位置。 |
| 限定选词翻译的语境 | 默认仅取选中词所在句，显示在线发送范围。用同一输入框里分别表示银行和河岸的两个 `bank` 验证。 |
| 研习开关只刷新本地词卡 | 用慢速模拟服务流式返回译文，反复切换英语和多语研习，确认只发一次请求且保留译文。dev.6 已实现；浮窗回归用例在分段返回期间切换三次，验证请求计数保持为一且已显示正文保留。 |
| 打通扩展词典一键安装 | 随包提供固定版本和校验值的来源清单。干净安装后直接安装法语词典，查到 `pain`。dev.6 已实现。安装包仅附固定提交地址及 SHA-256；独立空数据目录实测不选词典时无词库，只选法语时仅生成 fr.ykdict，重开查 pain 得到“面包”。 |
| 让卸载覆盖用户选定的数据位置 | 确认页列明要处理的设置和密钥。测试自定义数据目录下卸载、重装，核对收藏本和同目录其他文件。 |
| 让手动翻译明确引擎限制 | 节能引擎锁定语言时解释仅支持英译简中，并提供切换服务的入口。 |
| 测量划词到首段译文的耗时 | 对冷启动、连续使用和空闲后使用分别记录取词、引擎就绪和首段译文。根据结果决定是否短时保留进程，并量化内存代价。 |
| 把翻译错例加入回归 | 固定覆盖否定、条件和技术术语，检查语义是否保留，允许同义表达。 |
| 补齐源码包的研习测试资源 | 清单实测遗漏 `study-packs/`。纳入小型测试样例与构建说明，从解压的源码包复跑研习回归，完整词典可独立分发。 |

## 词典与研习

| 方向 | 改进与验收 |
| --- | --- |
| 统一多语点词 | 手动窗口与浮窗共用点词规则，保留日语拖选词组。独立规则测试已确认浮窗规则漏掉日语、韩语，仍需验证桌面入口。 |
| 统一 JSON 词包安装状态 | 设置页和收藏本统一用词包可用状态。导入 JSON、查词、重启后均应显示一致。dev.6 已实现；JSON 导入后两个按钮同步显示已安装，重载后仍能查词，也能补下完整词库。 |
| 隔离损坏词包 | 单个语言加载失败时，主程序及其他词典仍可使用，该语言提供重新安装入口。 |
| 减少交互中的重复查盘 | 五词典全开时，先测输入和拖选引发的查询及收藏文件读取次数，再合并重复操作。 |
| 词包下载进度与取消 | 展示已下载大小，能取到总量时再显示百分比。取消后可重试并保留原词包。 |
| 收藏本筛选与短时复习 | 支持筛选已收藏词和随机复习 10 个，沿用现有词头存储方式。 |

## 翻译与桌面操作

| 方向 | 改进与验收 |
| --- | --- |
| 按端点隔离限流状态 | 模拟服务 A 返回 429，切换到独立服务 B 后，B 的首个请求可以发出。 |
| 实测常用应用取词 | 复测 WPS PDF、浏览器内嵌 PDF、Word、VS Code，核对取词文本、焦点和剪贴板。dev.6 部分完成：Edge 的 .pdf 标签支持沿用 PDF 复制回退。在独立 Edge 配置中确认实际标题含零宽字符，并通过文本接口读到样例 bank；真实手势测试中出现只选到 n 及前台切换失败，浮窗完整路径待人工复验。 |
| 改善长文本处理 | 提示超限位置并支持选择部分翻译，再验证本地按句分段对段落、代码和取消操作的影响。 |
| PDF 按段落整理 | 同一选区里的正文合并排版断行，代码和表格保持原样。 |
| 按应用设置划词方式 | 每个应用可选自动翻译、先显示图标或暂停，支持从正在运行的应用选择。 |
| 手动翻译快捷键 | 支持 Ctrl+Enter 翻译和 Esc 取消，验证中文输入法选词、换行和取消。 |
| 显示 VS Code 终端快捷键状态 | 在诊断页显示注册是否成功，失败时提供手动翻译入口。 |
| 选择 VS Code 适配目标 | 稳定版和 Insiders 同时存在时显示版本和路径，安装后提示重启对应版本。 |
| 托盘显示暂停状态 | 同步更新托盘图标或提示文字，方便用户判断划词是否已暂停。 |

## 配置、安装与发布

| 方向 | 改进与验收 |
| --- | --- |
| 迁移失败可原地重试 | 写入前检查各语言收藏本的冲突，并验证中途失败后的目录状态。 |
| 提示设置尚未保存 | 有修改时提供保存并关闭或放弃。覆盖编辑 API 配置 A、切到 B 后关闭的路径。 |
| 便携版可带走研习资料 | 支持导出用户选定的收藏和词包，密钥沿用加密迁移。用两个 Windows 账户验收。 |
| 安装时解释内置英译中 | 清楚说明跳过通用模型下载仍可离线英译中，说明其他语言方向的模型要求。 |
| 提供轻量便携包 | 只带英汉词典与节能引擎，保留现有完整包。断网解压后完成首次英译中。 |
| 统一开发版标识 | 让 README 试用说明与实际构建版本一致，便于复测和反馈。 |
| 支持 macOS | WPF 为 Windows 专属框架，需整体移植到 Avalonia UI（保留 C#/.NET 业务层）或另起 macOS 实现；逐项盘点平台差异：选区读取（UI Automation → Accessibility API）、全局快捷键、系统托盘、TTS、设置/凭据存储（DPAPI → Keychain）、安装打包；离线引擎 llama.cpp 原生支持 macOS/Metal，可行性高。构建与验证需 macOS 实体机或云端 Mac（Hyper-V 无法虚拟化 macOS）。先出移植评估与分期方案再立项。 |
| 拓展目标系统到 Win10 与 Win7/8.1 | Win10：`installer/YiKe.iss` 的 `MinVersion=10.0.22631` 降至 10.0，并盘点代码中的 Win11 专属 API（grep `SupportedOSPlatform`、Windows 11 新增 Win32 调用），Hyper-V Win10 虚拟机验收安装与划词。Win7/8.1：.NET 10 客户端最低要求 Win10 1607，运行时层面不可行，需 .NET Framework 4.8 独立分支——预计失去单文件发布、节能引擎（现代 Python/ctranslate2 无 Win7 轮子）、llama.cpp 兼容性存疑，先按功能清单评估降级范围与成本再立项；两个系统均已停更，需向用户明示安全风险。 |
