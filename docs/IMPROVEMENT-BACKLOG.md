# 译刻 YiKe 改进清单

三轮审阅以 `main` 的 `b86c71e` 为基线。以下优先级是开发排期建议。选题前先核对当前实现和用户指令，已解决的条目按实际结果更新。除注明的静态或独立验证外，验收场景尚待运行。

每次落实改进后，在同一批变更中更新对应条目，记录完成或部分完成的状态、实际改动和验证结果。尚未验证的内容标为待验证。清单外的改进落实后补录。

本批 Windows 主线改进通过 Release 构建、核心回归 190 项、视觉回归、VS Code 适配测试 17 项和五种完整词包查词。UI 回归通过 77 项，1 项因缺少节能翻译组件失败。

## 优先考虑

| 方向 | 改进与验收 |
| --- | --- |
| 保留手动翻译草稿 | 已实现。保存设置成功后用新配置重开手动翻译窗口，从内存恢复原文、选区和滚动位置。新增 UI 用例覆盖草稿恢复、新服务标识和零翻译请求，已通过。核心回归 182 项和视觉回归通过。完整 UI 回归 62 项通过，1 项因缺少节能翻译组件失败。 |
| 限定选词翻译的语境 | 已实现。手动窗口仅取选中词所在句作为语境，在线模式显示「选词 + 所在句」，按钮提示展示实际发送的原句。核心回归 183 项通过；UI 回归 63 项通过，1 项因缺少节能翻译组件失败；视觉回归通过。同一输入框的两个 `bank` 已验证分别隔离为银行句和河岸句，真实模型译文仍待实测。 |

| 打通扩展词典一键安装 | 随包提供固定版本和校验值的来源清单。干净安装后直接安装法语词典，查到 `pain`。dev.6 已实现。安装包仅附固定提交地址及 SHA-256；独立空数据目录实测不选词典时无词库，只选法语时仅生成 fr.ykdict，重开查 pain 得到“面包”。 |
| 让卸载覆盖用户选定的数据位置 | 已实现代码，待安装验收。卸载器读取数据位置指针，确认页列明当前及旧位置的设置与密钥；仅显式勾选或 `/DELETEDATA=1` 时删除这些文件，保留收藏本、词包、位置记录和其他文件。安装脚本已加入自定义目录保留、重装与定向删除检查。核心回归 183 项通过；UI 回归 63 项通过，1 项因缺少节能翻译组件失败；视觉回归及 PowerShell 语法检查通过。本机缺少 Inno Setup、PowerShell 7 和安装包，尚未编译或运行安装验收。 |
| 让手动翻译明确引擎限制 | 已实现。节能引擎手动窗口显示仅支持英语到简体中文，锁定语言方向并提供「切换翻译服务」入口；点击打开设置，不发送翻译请求，保存后沿用草稿恢复。核心回归 183 项通过；UI 回归 63 项通过，1 项因缺少节能翻译组件失败，1 项因桌面前台权限跳过；视觉回归通过。 |
| 测量划词到首段译文的耗时 | 已实现。构建测试程序后，从仓库根目录运行 `./tests/YiKe.Tests/bin/Release/net10.0-windows/win-x64/YiKe.Tests.exe --selection-latency ./local-runtime ./artifacts/selection-latency.json`。在专用窗口按提示拖选整句，分别测冷启动、连续使用和空闲释放后再用。报告仅含各阶段距鼠标松开的毫秒数、引擎进程工作集和空闲等待时长。核心回归 183 项及视觉回归通过，UI 回归 65 项通过（含模拟引擎计时），1 项因缺少节能翻译组件失败。真实桌面测量因缺少通用引擎运行目录跳过，进程保留策略待数据评估。 |
| 把翻译错例加入回归 | 已添加否定、限制条件和技术术语样例，核心回归检查可接受的同义表达和明显错译。`YiKe.Tests.exe --semantic-live ./local-runtime` 使用同一批样例验证通用离线模型；本机缺运行目录，真实结果待测。 |
| 补齐源码包的研习测试资源 | 已完成。源码包包含五种语言的小型样例和构建说明，完整 `.ykdict` 独立分发。发布校验要求这些文件齐全，已验证缺少韩语样例的归档会被拒绝。按发布脚本的收集和压缩规则生成测试归档，解压后恢复依赖并构建成功，核心回归 183 项通过；UI 回归 65 项通过（含五语词包与研习用例），1 项因未提供节能翻译组件失败。 |
