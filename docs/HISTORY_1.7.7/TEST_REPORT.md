# 译刻 1.7.7 多组在线 API 验收

2026-10-26（America/Denver）。本轮新增最多 32 组在线 API 配置，分别保存名称、地址、Windows DPAPI 加密密钥、模型、超时和指令角色。同一地址支持多个账号；当前选择在保存和重启后保留。翻译只使用当前配置，不向其他配置并行发送，也不自动换服务商。

设置中可新增、重命名、删除和切换。窗口内切换保留未保存编辑，点击保存后统一提交并启用当前 API。旧版单 API 自动转换为默认配置，原密钥的服务标识及端点绑定保留。普通配置导出包含所有非密钥信息；导入为每一组生成新密钥绑定。加密迁移包携带全部已保存密钥，导入后用新本机绑定重新加密，兼容旧版单 API 迁移包。

配置密钥采用互不相同的服务标识及规范化 HTTPS 端点分开保存，切换模型列表和连接测试时取消旧请求并隔离迟到结果。先写新凭据，再原子提交配置指针；配置提交失败时原配置和原密钥仍可使用，窗口编辑保留。删除配置在提交成功后仅清理已移除配置的密钥，不影响其他账号。普通 JSON、发布归档和诊断不含真实密钥。
