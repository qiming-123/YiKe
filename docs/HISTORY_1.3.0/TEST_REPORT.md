2026-10-24（Asia/Shanghai）。Windows x64 build 26300，Intel Core Ultra 9 275HX，约 32 GB 内存、24 个逻辑处理器。低配策略使用注入硬件快照验证，不冒充实体低配性能。

安装器改为约 61 MB 的按需下载版，保留完整自包含应用、CPU 引擎及 C++ / .NET 运行组件。安装目录之后显示模型选项：本次不下载、轻量 Qwen3 0.6B Q4_0、标准 Qwen3 1.7B Q4_K_M、两种都下载。硬件信息由随包应用的只读入口生成，与运行时共享硬件策略；根据物理内存、当前空闲内存、CPU 数量和兼容性推荐，物理配置不足的选项禁用。升级默认不下载。

模型来自固定仓库提交，核对 SHA-256 后才允许进入文件安装步骤。已有有效模型不重新下载；不下载保留现有模型和偏好。运行时遵循安装选择，自动模式能使用单独安装的轻量模型；重型模型仍受硬件 / 空闲内存保护。未安装模型时打开设置并明确提示补装方式，不自动下载或转发在线 API。模型偏好只写安装目录 local-model.ini，原配置及密钥文件不改写。完整离线便携包仍包含两种模型。

安装流程验收使用独立 AppId（YiKe.Installer.ModelSmoke）和临时安装目录；不改实际安装注册信息，不设置真实自启动。其代码路径与正式安装器共用模型页面、下载校验、文件复制与模型偏好，仅隔离安装身份及实际用户的启动 / 退出操作。另用正式签名安装器完成 D:\YiKe 升级和保留校验。错误哈希用固定小型公共文件代替模型，确认哈希被拒绝且目标应用文件未写入；不关闭 TLS、证书或哈希校验。

安装页的交互截图核验未完成：桌面工具返回“Computer Use app approval timed out”，没有将该项计为通过。模型页采用 Inno 自带选项页布局；本轮没有人为点击真正的安装按钮完成 GUI 全流程，功能通过相同安装代码的静默选项及真实下载 / 安装验证。应用设置页的无模型状态另有 WPF 渲染与控件检查。

下载依赖用户网络和 Hugging Face 的可达性；本机曾遇到网络中断，重试后成功，不承诺所有地区、代理或网络均可直连。失败时可重试或选择不下载；需要完全离线分发时使用含双模型的便携包。安装器实现依据 [Inno 下载页文档](https://jrsoftware.org/ishelp/topic_isxfunc_createdownloadpage.htm) 和 [临时文件提取](https://jrsoftware.org/ishelp/topic_isxfunc_extracttemporaryfile.htm)。

保留小型模型的质量边界：部分语言可能省略、措辞生硬或繁简混用；协议成功不表示 22 项语言均通过质量验收。WPS、Edge 实际划词验收分别来自 1.2.2 / 1.2.1，相关代码保留；本轮不冒充重新执行全部桌面应用矩阵。完整零开发环境隔离来自 1.2.0，本轮未使用另一台干净 Windows 或整机物理断网；离线运行组件的固定版本不变。历史报告在 HISTORY_1.2.2/。
