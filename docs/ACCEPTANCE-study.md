# 译刻 2.0.0 开发版 · 研习体验验收

供两位开发者复测。本页放在源码仓库的 docs 目录。

| 操作 | 通过条件 |
| --- | --- |
| 新用户打开设置，走完欢迎页；另用新配置点跳过 | 可看到划词、手动翻译、研习收藏及暂停应用的引导。两种路径重启后都不自动重复，使用指南可重看 |
| 在设置开启英语研习、计算机释义，保存后划选英语词 | 开启时有功能说明，第一次出现英语收藏按钮时有星标提示，再次查词不重复 |
| 在外观设置填入 Code 并保存 | 在 VS Code 划词不响应，其他支持的应用仍可划词；移除此项后恢复 |
| 在浅色和深色下划词，点击小图标 | 图标在屏幕工作区内，打开译文且不抢走原应用焦点；星标、喇叭有工具提示和可访问名称 |
| 在手动、划词浮窗和单词收藏本分别查 pain | 只有英语时直接显示；安装并启用法语词典后先出现英语、法语两个选择。选法语显示面包，收藏后只在法语本出现；另选英语可独立收藏 |
| 手动输入 They sat on the bank of the river.，选 bank，点按原句译选词；再用 I called my bank. | 通用本地或在线服务分别返回河岸和银行一类译法。不能返回整句。节能英译中仅支持整句翻译 |
| 手动中译英粘贴「飞机即将起飞」，译文若含 take off 则拖选整个词组 | 可查看本地词典所收录的词组义项，点星标后英语本中能复习、导出并删除该词组 |
| 在浮窗已完成的英文译文里点击单词 | 展示本地释义。有收录的相邻英语词组可切换；词典未收录时明确提示 |
| 展开目标语言字段旁的问号，再收起 | 能看到默认语言和识别规则；键盘也可操作 |
| 已有用户原地更新 | 桌面快捷方式、离线模型、词包、收藏及设置仍在；分别验证已安装程序的词典和离线翻译 |

## 紧凑浮窗与多语离线验证

- 在浮窗依次打开原文、复制译文、切换扩展。固定后拖动左上方标题；译文更新、展开原文时保持拖到的位置。取消固定后再划词，应在新选区附近显示。
- 收藏后星形变为实心，再次查同一语言的同一词仍显示实心。在收藏本删除后重新查词应恢复空心。
- 英语词条可分别选英音和美音，使用 Windows 对应地区的离线 SAPI 语音。缺少对应语音时应明确指出地区。
- 使用轻量 Qwen3 模型进行多语言整句翻译，比较相同原文、相同模型的新旧引擎工作集峰值。记录输出并单独核对译文质量。低于启动门槛时应显示内存提示。
用「按原句译选词」翻译含 bank 的句子。核对主译文下的「其他词义」默认收起，展开可读到本地词典的银行、岸等义项，原译文仍可复制。换查无词典记录的词后，上一个词的备选释义应消失。
在「翻译服务 → 英语研习 → 其他选项」展开语言列表，滑到末项。只开启日语和法语后保存，重新进入设置核对勾选；查词及其他词义应只使用所选的已安装扩展词典。关闭多语总开关后再开启，应恢复原勾选，原收藏仍可在对应语言本中复习。
