# 1.3.0 安装模型与推荐

安装器不再捆绑模型权重；提供本次不下载、轻量、标准及两种模型四项。硬件检测由随包自包含应用的 `--installer-info` 只读入口完成，与运行时共享 `LocalHardware` 策略；未能检测配置时默认不下载。推荐会考虑当前空闲内存，物理配置不足的重型选项禁用。仅下载模型文件，无额外环境安装。

模型 URL 来自 local-model.lock.json 的固定提交，编译时生成 installer/model-downloads.iss。下载器只接受预置 SHA-256，完整校验后才继续安装；下载失败、取消或哈希错误不能写入程序文件。已有正确模型先校验后复用，不重复下载。不选下载不会删除旧模型。静默安装默认不下载，可显式指定 `/LOCALMODELS=none|light|standard|auto`，其中 auto 表示下载两种并按硬件自动选择；非法参数拒绝安装。

安装目录 local-model.ini 仅保存 `[LocalModel] Selection=light|standard|auto`，不含密钥。明确选择轻量 / 标准时优先使用该种类，仍需满足硬件和空闲内存门槛。auto 只在已安装模型中选择，不会因为机器性能高而要求缺失的标准模型；不会在内存不足时强行加载唯一的重型模型。跳过下载保留该文件；无该文件的完整便携包默认自动选择。所有模型加载仍先核对运行文件的固定 SHA-256。

下方保留原双模型运行策略及质量说明，其硬件 / 内存保护继续生效。
# 本地模型与电脑配置自动适配

1.2.0 完整安装包与便携包同时内置两种模型及全部运行库。满足运行条件时，安装 / 完整解压后即可离线翻译，默认简体中文。首次启动不下载模型，不需要 API、Ollama、Python、.NET 安装或显卡驱动。

| 检测结果 | 行为 |
| --- | --- |
| 物理可用总量不足 7 GiB（约 8 GB 标称内存），或少于 4 个逻辑处理器，或不满足 x64 / SSE4.2 | 阻止本地模型加载，显示原因；用户可自行选择在线 API |
| 当前空闲物理内存不足 2.5 GiB | 暂不加载，关闭占用内存的程序后可重试 |
| 总量至少 14 GiB、空闲至少 5 GiB、至少 8 个逻辑处理器 | 标准模型 Qwen3 1.7B Q4_K_M；最多 6 个推理线程，6144 上下文，256 / 128 批处理 |
| 其他满足本地门槛的配置 | 轻量模型 Qwen3 0.6B Q4_0；最多 2 个推理线程，4096 上下文，128 / 64 批处理 |

总量门槛预留了集成显卡 / 硬件保留内存的差异，不把标称 8 GB 严格等同于 8 GiB 可用。上述策略是本工具的产品门槛，并非模型作者的通用最低要求。逻辑处理器数量不能代表所有 CPU 的真实性能；本轮未在真实 8 GB 老电脑上测速度。

每次加载重新评估配置和当前空闲内存；运行期间不反复切换模型。引擎使用 BelowNormal 进程优先级，关闭主动轮询，限制生成和提示处理的线程数。轻量 / 标准档分别闲置约 5 / 15 分钟释放模型，空闲内存过低时提前释放；请求前发现不足 1 GiB 时停止引擎并显示提示。下一次加载会重新选档。

首次加载校验对应模型及引擎 SHA256。进程释放后保留本次运行中的校验记录；未改变的文件不重复完整散列，文件大小、时间或引擎文件集合发生变化时重新校验。退出应用后不保留此内存缓存。翻译缓存按实际模型隔离，换档不会直接复用另一模型的译文。

设置页显示当前检测到的内存、逻辑处理器数量及预计加载档位，约 15 秒更新一次。配置不满足时禁止测试和保存本地模式，界面显示原因；临时内存不足可以稍后重试。不自动转发到在线服务，也不清除已有的在线地址和加密密钥。

标准模型固定版本 daeb8e2d528a760970442092f6bf1e55c3b659eb，1,282,439,264 字节；轻量模型固定版本 13ac06624948e4d8589cb4b6f90100837342fcb8，428,970,080 字节。均来自 ggml-org 的 [Qwen3 1.7B](https://huggingface.co/ggml-org/Qwen3-1.7B-GGUF) / [Qwen3 0.6B](https://huggingface.co/ggml-org/Qwen3-0.6B-GGUF)，原始模型来自 Qwen，Apache License 2.0。固定下载地址、SHA256 和清单见 local-model.lock.json 与 assets/local-package.json。引擎仍为 llama.cpp b11796，使用 app-local Microsoft CRT，不安装系统组件。

模型质量有差异。两档都执行了 5 组真实多语言样例，但这只验证程序流程，不代表翻译质量合格或全部语言均已验收。轻量模型的日文样例遗漏了关闭窗口前的条件，中文技术样例使用了繁体和不自然措辞；标准模型也会省略对象词。重要或复杂文本应结合原文核对，必要时自行选择更合适的在线服务。

程序只连接自己的随机 127.0.0.1 引擎端口，启用临时鉴权并核对监听进程，不保存提示词或生成日志。只移动 YiKe.exe 不包含模型；请使用完整安装包或完整解压目录。建议保留至少 6 GB 空闲磁盘。零环境成品验收见 ZERO_ENVIRONMENT.md，真实结果见 LOCAL_MODEL_LIVE.json 与 LOCAL_MODEL_LIGHT_LIVE.json。
