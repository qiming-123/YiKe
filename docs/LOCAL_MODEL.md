# 本地引擎（1.8.0）

默认英译中节能引擎随安装包提供：OPUS-MT en-zh、CTranslate2 INT8 CPU、独立 CPython 运行目录。没有系统 Python 依赖，也不需要启动常驻服务。英文词典命中直接返回；句子通过 stdin 发送给按次启动的受管子进程，完成/取消/退出后释放。两线程、禁用 packed GEMM，避免底层缓存显著抬高私有内存。运行文件先按嵌入清单核对SHA-256。

节能引擎只提供英文→简体中文。其他方向应选择通用多语模型或在线服务；不会自动外发。最多512 source token/单行，超过报错，不截断。段落换行保留。词汇/语境有歧义时仍可能误译。

## 原通用模型

已有 Qwen3 0.6B Q4_0 与1.7B Q4_K_M 保留在 local-runtime。轻量模型现在使用3072上下文、1536输出、64/32批量、1分钟空闲释放；最低空闲门槛1.75GiB。标准门槛5GiB，其他硬件检查保持。启动程序不再提前加载模型。

安装器可选择不下载、轻量、标准、两种；升级默认不下载并保留已存在文件。选择“本次不下载”仍可直接使用内置英译中引擎。下载的通用模型来自固定提交，完整校验SHA后使用。`/LOCALMODELS=none|light|standard|auto` 控制静默安装选择。

更改引擎在设置的本地翻译区域完成；模型选择和API配置相互独立。低内存目标优先通过专用英译中引擎实现，未声称降低门槛就能保证通用模型可用。
