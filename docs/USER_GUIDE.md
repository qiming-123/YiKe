# 译刻 YiKe 用户手册

适用于 YiKe 2.0.0。译刻是 Windows 划词翻译工具，支持本地离线翻译、自选在线 API、单词研习和收藏。

只需日常使用，请阅读 [精简版](QUICK_START.md)。

## 1. 安装与启动

### 系统要求

- Windows 10 22H2 或更高版本、Windows 11，x64。
- 不提供 ARM64 版本；不支持 macOS、Windows 7 或 8.1。
- 安装版不需要另行安装 .NET、Python、Ollama 或显卡驱动。

### 安装

运行 `YiKe-Setup-2.0.0-win-x64.exe`，按向导操作。可选项包括：

- **本地通用模型**：轻量、标准、两种都下载，或本次不下载。即使不下载，也可使用内置英译中节能引擎。
- **研习词典**：日语、韩语、法语、德语、西班牙语，可分别选择。
- **桌面快捷方式**：默认不创建。
- **登录 Windows 时启动**：默认不开启，也可稍后在设置中修改。
- **VS Code 适配**：用于编辑区和终端取词；安装后重新打开对应 VS Code 窗口。

覆盖安装会保留已有设置、密钥、模型和词典。已有模型通过校验后会直接复用。

当前安装包未签名时，Windows 可能显示安全提示。请只使用可信来源发布且哈希相符的安装包。

### 便携版

解压 `YiKe-Portable-2.0.0-win-x64.zip` 后运行 `YiKe.exe`。请保留整个目录，不要只移动 EXE。便携版包含完整运行组件和通用模型，体积较大。

便携配置保存在程序自己的 `data` 目录，同时可能在本机用户目录建立副本。不要公开分发带有个人配置的便携目录。

### 首次启动

启动后会出现主界面和使用教程。教程可跳过，之后点击左侧“使用指南”重新打开。

程序常驻系统托盘：

- **双击托盘图标**：打开主界面。
- **右键托盘图标**：暂停或恢复自动翻译、打开设置、手动翻译或退出。
- 手动翻译窗口打开时，自动划词暂停；关闭后恢复。

## 2. 划词翻译

### 自动翻译

1. 在支持的应用中拖选文字，或双击一个单词。
2. 松开鼠标，等待译文浮窗出现。
3. 阅读、复制译文，或展开其他功能。

空选区不会弹出翻译。原文最多 2,000 个 Unicode 码点，超限时请缩短选区，程序不会静默截断。

### 点击图标后翻译

在“外观与行为”勾选“划词后显示图标，点击才翻译”并保存。之后划词只显示“译”图标，点击后才启动翻译。

图标阶段不加载翻译模型，也不发送原文。图标约 15 秒后或来源窗口改变时消失。

### 翻译浮窗

- **查看原文**：展开或收起原文；PDF 整理时仍可查看整理前文本。
- **复制译文**：把当前译文写入剪贴板。
- **取消**：停止当前请求。在线请求取消后，服务商是否计费取决于其规则。
- **重试**：再次调用翻译服务，可能再次产生在线用量。
- **固定翻译浮窗**：保留当前浮窗并暂停接收新划词；固定后可拖动标题移动位置。
- **关闭翻译**：关闭浮窗并取消当前请求。
- **打开设置**：进入主界面。
- **翻译扩展**：临时开关技术释义、英语研习和多语研习。研习开关只刷新本地词卡；技术释义变化可能重新请求翻译。

浮窗会在屏幕工作区内调整位置，不会主动抢走来源应用的焦点。

## 3. 手动翻译

从主界面左侧或托盘菜单打开“手动翻译”。

1. 粘贴或输入原文。
2. 选择源语言和目标语言；源语言默认“自动识别”。
3. 点击“翻译”。
4. 需要停止时点击“取消”。

### 按原句译选词

需要区分多义词时：

1. 在原文输入框中选中一个词或词组。
2. 点击“按原句译选词”。
3. 程序只翻译选词，并把选词所在句作为语境，不发送输入框中的其他句子。

在线模式会显示“在线发送：选词 + 所在句”；将鼠标停在按钮上可核对实际句子。

节能引擎固定英译简中，不提供此选词入口。需要其他语言方向时，请先在设置中切换通用多语模型或在线服务。

### 手动窗口中的研习

展开“单词研习”后，可输入或选中单词、词组查看本地释义。译文中可点击单词，或拖选词组查询。查询结果支持收藏；英语单词支持英音、美音朗读。

保存设置后，如果手动窗口重新打开，程序会从内存恢复原文、选区和滚动位置，不会自动重新翻译。关闭手动窗口不会把草稿保存到磁盘。

## 4. 翻译服务

在“翻译服务”页选择本地离线或在线 API，修改后点击“保存设置”。

### 本地引擎对比

| 引擎 | 用途 | 特点 |
| --- | --- | --- |
| 英译中节能引擎 | 英文单词、句子 → 简体中文 | 随包提供；按需启动，完成后释放；无需通用模型 |
| 通用多语模型 | 其他语言方向、可选模型补充说明 | 使用 Qwen3；需要安装模型并满足内存要求 |

节能引擎仅支持英译简中，不支持中译外或繁体目标。单行最多 512 个模型 token，超限会报错而不截断。

通用模型要求：

- 轻量模型约需 1.25 GiB 空闲内存。
- 标准模型约需 5 GiB 空闲内存。
- 模型在首次实际翻译时加载；通用模型空闲后释放。
- 内存不足时可关闭其他程序后重试，或改用节能引擎、在线服务。

本地失败不会自动把原文转发到在线服务。

### 目标语言与流式显示

- **目标语言**：默认简体中文，可从列表选择或直接输入语言名称。
- **逐步显示译文**：开启后，译文分段显示；关闭后等待完整结果。

### 技术释义

勾选“技术释义”后，译文下方可显示计算机术语、命令、作用、用法和示例。内置术语说明在本地提供。

“用模型补充计算机用法与示例”会让标准本地模型或兼容在线 AI 额外生成说明。在线服务每次翻译最多增加一次说明请求，可能计费。关闭模型补充仍可使用内置术语说明。

## 5. 在线 API

### 配置步骤

1. 将“翻译方式”设为“在线 API”。
2. 选择服务预设：OpenAI、自定义兼容服务或 DeepL。
3. 填写 API 根地址和 API Key。
4. 兼容 AI 服务可自动获取模型列表，也可手动填写模型名称。
5. 点击“测试连接”验证，再点击“保存设置”。

“测试连接”只发送固定样例 `Hello, world!`，可能计入服务用量。模型检测只请求模型列表，不发送原文；返回列表不代表每个模型都支持翻译。

### DeepL

- Free：`https://api-free.deepl.com/v2`
- Pro：`https://api.deepl.com/v2`
- 使用专用文本翻译协议，不需要获取或填写模型列表。

### 多组 API 配置

最多保存 32 组配置。通过“新增 API”建立配置，用“在线 API 配置”下拉框切换编辑。每组可拥有独立名称、地址、密钥、模型和网络选项。

- 切换配置会保留本窗口内尚未保存的编辑。
- 点击“保存设置”后统一生效。
- “删除此配置”需确认，并在保存后删除该配置及其本机密钥；其他配置不受影响。
- 更换密钥时点击“更换密钥”。留空不会清除旧密钥；如需删除，请使用“数据与迁移”中的“删除当前服务的本机密钥”。

### 高级网络选项

- **首个译文等待上限**：限制等待首个响应的时间。
- **整个请求上限**：限制整个请求持续时间。
- **固定指令角色**：可选 `system` 或 `developer`，通常无需修改。

密钥与规范化服务地址绑定。修改地址后，原地址的密钥不会被发送给新地址。

## 6. 英语与多语研习

### 英语研习

在“翻译服务”开启“英语研习”并保存。选中或点击英语单词后，可查看本地词库中的：

- 音标和多个释义
- 英文定义
- 搭配与例句
- 其他词义
- 相邻且已收录的英语词组

点击星标收藏单词。英语单词可分别使用英音或美音朗读；朗读使用 Windows 离线语音，不朗读整句，也不进行语法分析。

若系统缺少对应语音，按界面提示打开 Windows 语音设置安装。

### 多语研习

支持日语、韩语、法语、德语和西班牙语词典。

1. 在“翻译服务 → 其他选项”展开多语研习。
2. 下载所需词典，或在收藏本中安装本地词包。
3. 勾选需要使用的语言。
4. 点击“保存设置”。

同一个词命中多种语言时，先选择词条语言，再查看或收藏。各语言收藏本相互独立。

### 安装词包

收藏本提供三种方式：

- 点击对应语言的下载按钮，获取官方固定版本词包。
- “从文件安装”：选择 `.ykdict` 或 `.json` 文件。
- “从网址安装”：输入 HTTPS 词包直链并下载。

安装后保存研习开关设置。下载失败时可重试；已有词典不会因下载失败而被主动替换。

## 7. 单词收藏本

从主界面左侧打开“单词收藏本”。

- 在顶部切换英语或其他语言收藏本。
- 选择单词后先回想词义，再点击“显示释义”。
- **查词**：检索内置英语词库和已启用的已安装词典，并可直接收藏。
- **删除所选**：从当前语言收藏本删除选中的词。
- **导出文本**：导出词头及当前本地词典释义；词典未收录时至少保留词头。
- **更改保存位置**：合并已有收藏到新目录，原目录保留副本。

收藏只保存主动收藏的词头，不保存翻译历史。释义在查看或导出时从本地词典读取。

## 8. 外观与应用行为

在“外观与行为”页调整：

- **视觉风格**：深色赛博朋克或浅色 Y2K 银晶。选择后立即预览，保存后记住。
- **译文字号**：调整浮窗正文字号。
- **划词后显示图标**：关闭为自动翻译，开启为点击图标后翻译。
- **智能整理 PDF 正文断行**：保守合并排版断行和词典确认的断词，保留段落、代码及不确定的连字符。
- **在这些应用中暂停划词**：每行填写一个进程名，例如 `Code`；不需要 `.exe`。留空表示不排除应用。
- **登录 Windows 时启动译刻**：修改当前用户的启动注册项。
- **WPS / Edge PDF 自动划词翻译**：关闭后停止该自动路径，不影响手动翻译。

未点击“保存设置”的修改不会成为持久配置。

## 9. 应用适配

### 普通应用

浏览器、记事本及其他支持文字选区接口的应用可直接拖选或双击。并非所有应用都提供相同接口；不支持时可使用手动翻译。

密码框、空白区域、桌面图标、文件列表和非文字控件不会作为普通文字选区读取。

### WPS 文字与 PDF

WPS 文字支持普通选区。WPS PDF 使用“选择”工具划选文字；直接接口不可用时，程序可自动执行一次复制取词，并尽量恢复原剪贴板。

自动复制只接受本次新复制的内容，不覆盖其他应用在此期间的新复制。特殊剪贴板格式或可恢复内容超过 64 MiB 时，请手动按 `Ctrl+C` 使用兼容路径。

扫描图片 PDF、禁止复制的文档仍需先取得可用文字层。

### Edge PDF

Edge 中的 `.pdf` 标签可使用 PDF 复制回退。其他浏览器或阅读器是否可用取决于其实际窗口和文字接口。

### VS Code 编辑区

在“外观与行为”点击“安装 / 更新 VS Code 适配”，或在安装向导中选择该任务。安装后重新打开 VS Code。

适配使用本机扩展读取当前编辑区选区，不需要开启读屏模式。卸载译刻不会自动卸载该 VS Code 扩展；不再需要时，请在 VS Code 扩展页卸载 `yike-local.yike-selection`。

### VS Code 终端

选中终端文字后按 `Ctrl+Alt+Y`，程序会显式复制并翻译该选区。此操作会更新剪贴板。没有新选区时不会读取旧剪贴板内容。

## 10. 数据、备份与迁移

在“数据与迁移”页管理本机数据。

### 更改数据目录

“更改数据目录”会移动设置和默认收藏本的正常使用位置，旧文件保留为副本。词包仍以默认数据位置管理。

### 普通配置导出与导入

- 导出文件包含翻译及界面设置，不包含 API Key。
- 导入后使用新的本机密钥绑定，需要重新填写或导入密钥。
- 无效配置不会改变当前设置。

### 加密迁移包

用于在电脑或 Windows 账户之间迁移 API 配置及密钥：

1. 点击“导出加密迁移包”。
2. 设置至少 10 个字符的密码。
3. 保存 `.yike` 文件，并另行保管密码。
4. 在目标电脑选择“导入加密迁移包”，输入密码。

密钥在目标账户中重新使用 DPAPI 加密。不要把迁移包和密码一起公开传输。

### 删除当前服务密钥

“删除当前服务的本机密钥”只删除当前配置对应的密钥，不影响其他 API 配置。

## 11. 隐私与网络

- 默认不保存翻译历史，不记录原文、译文或请求体日志，不包含遥测。
- 本地翻译的原文只在本机处理，不会自动转发在线服务。
- 在线翻译会把当前原文发送到所选服务；选词语境翻译只发送选词及其所在句。
- 在线密钥使用 Windows DPAPI CurrentUser 加密，只适用于当前 Windows 账户。
- 模型检测只发送模型列表请求；连接测试只发送固定样例。
- 用户主动复制译文、PDF 复制回退和 VS Code 终端快捷键会使用剪贴板；普通划词不读取剪贴板。
- 内存缓存仅用于本次运行中的最近结果，不作为磁盘历史保存。

## 12. 卸载

默认卸载只删除应用和快捷方式，保留设置、密钥、收藏和其他数据，重装后可以继续使用。

交互卸载时勾选“同时删除上述设置和已保存的 API 密钥”才会清理数据。确认页会列明当前及旧数据位置中的：

- `settings.json`
- `credentials\*.bin`

收藏本、词包、数据位置记录和同目录其他文件不会被递归删除。静默卸载默认保留数据；只有显式添加 `/DELETEDATA=1` 才执行上述定向清理。

卸载译刻不会自动移除 VS Code 扩展。

## 13. 常见问题

### 划词后没有浮窗

- 确认托盘菜单没有暂停自动翻译。
- 检查应用是否列入“在这些应用中暂停划词”。
- 图标模式下需要先点击“译”。
- 手动窗口或固定浮窗打开时，不会接收新划词。
- 确认选中的是可读取文字，而不是图片或空白区域。
- 仍无法取词时，使用手动翻译。

### 本地模型不可用

检查是否已安装通用模型及当前空闲内存。只使用英译中时，可切换节能引擎，无需下载通用模型。本地失败不会自动改用在线服务。

### 在线翻译失败

检查 HTTPS 根地址、API Key、模型名称和账户额度。更换地址后需填写绑定到该地址的密钥。程序不会自动重发可能已计费的请求；需要时请主动点击“重试”。

### 翻译结果不准确

尽量选取完整句子，多义词可使用手动窗口的“按原句译选词”。本地和在线模型仍可能出现多义词、否定、条件或术语误译，重要内容请人工核对。

### PDF 无法取词

确认文档包含可复制的文字层。扫描图片需要先进行 OCR；特殊文档可手动复制或改用手动翻译。

### VS Code 适配无效

重新打开 VS Code 窗口，并在设置中重新安装或更新适配。终端请使用 `Ctrl+Alt+Y`，而不是等待普通拖选。

### 单词无法朗读

确认当前词条是英语单词，并在 Windows 语音设置中安装对应英语语音。词组和整句不提供朗读按钮。
