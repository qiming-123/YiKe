# 1.2.0 普通用户零环境首次使用验收

运行 YiKe-Setup-1.2.0-win-x64.exe 安装后启动，或完整解压 YiKe-Portable-1.2.0-win-x64.zip 并双击 YiKe.exe。满足本地硬件门槛的电脑默认离线翻译成简体中文，无需配置软件环境、地址或密钥，第一次启动也不联网下载运行组件。

2026-10-24，实际便携成品已在全新的中文目录解压并运行：

- 全新空用户目录，无译刻配置、凭据、外部模型缓存，未点击保存。
- 清空继承环境，PATH 仅含 Windows System32；DOTNET_ROOT / DOTNET_ROOT_X64 指向不存在的目录，DOTNET_MULTILEVEL_LOOKUP=0，运行库解压位置从空目录开始。
- 主程序使用内置 fxr / hostpolicy；实际观察 82 个应用原生模块及 36 个引擎模块，均来自完整包、其临时解压目录或 Windows 系统目录。三个核心 Microsoft CRT 与 OpenMP 从随包目录加载。
- 33 个离线模型 / 引擎文件逐个校验；默认简体中文，不填写 API / 模型，实际界面返回“本地翻译成功，已就绪；无需配置或密钥。”。
- 本地引擎由应用创建并仅在 127.0.0.1 监听。结束测试后引擎退出，原安装版恢复，原有 3 个用户数据文件字节完全相同。

详见 ZERO_ENVIRONMENT_RESULTS.json。该检查隔离开发环境与用户配置，未使用另一台干净 Windows 机器，也未断开整机网络。设置不可用代理不等同于物理断网，不以此宣称整机禁网测试通过。

低于硬件门槛时，程序明确提示本地不支持或内存不足，不自动发送原文到在线服务。选择策略见 LOCAL_MODEL.md。源码包供开发者构建使用；普通用户无需执行 bootstrap-local.ps1 或任何环境安装脚本。
