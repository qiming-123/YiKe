## 已知边界

模型列表只说明账户可见的模型 ID，不能证明每个模型支持 Chat Completions 或文本翻译。没有自动发送可能计费的翻译样例来逐个测试模型。配置服务本次模型查询仍返回网络错误，真实模型列表获取和在线多语种译文质量尚未验收；现有手动模型输入继续保留。未修改用户的服务地址或密钥，也未关闭 TLS 验证。

本次没有重跑全部真实应用鼠标矩阵。VS Code 扩展仍为 1.0.2，代码未改；历史实际选区结果见 HISTORY_1.0.2_TEST_REPORT.md。1.0.3 签名验收见 HISTORY_1.0.3_TEST_REPORT.md。干净机器、跨机器、多屏、完整读屏仍待补验。本轮源码包未再做独立重建，历史重建记录保留原版本号。
