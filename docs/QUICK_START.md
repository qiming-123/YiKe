# 译刻 YiKe 精简手册

适用于 YiKe 2.0.0。源码试用版在设置中标为 `2.0.0-dev`。完整说明见 [详细版用户手册](USER_GUIDE.md)。

## 1. 安装

运行 `YiKe-Setup-2.0.0-win-x64.exe`。

- 支持 Windows 10 22H2+ / Windows 11 x64。
- 不下载通用模型，也能使用内置英译中节能引擎。
- 需要其他离线语言时，再选择轻量或标准通用模型。

## 2. 划词翻译

在支持的应用中选中文字，松开鼠标即可翻译。

- 通用离线模型首次使用或空闲退出后，需要等待模型加载。
- 只想点击后翻译：在“外观与行为”开启“划词后显示图标，点击才翻译”。
- 浮窗可复制译文、查看原文、取消或重试。
- 固定浮窗后可拖动位置，并暂停接收新划词。
- 托盘提示会显示暂停状态，右键可切换。在“外观与行为”可以为单个应用指定划词方式。

## 3. 手动翻译

从主界面或托盘菜单打开“手动翻译”，输入原文，选择语言，点击“翻译”。

`Ctrl+Enter` 翻译，`Esc` 取消。长文可先选中一段，再点“翻译选中部分”。

多义词可选中词或词组，再点“按原句译选词”。程序只翻译选词，并仅使用其所在句作为语境。

节能引擎仅支持英译简中。需要其他语言时，点击手动窗口的“切换翻译服务”。

## 4. 选择翻译服务

在“翻译服务”中选择：

- **英译中节能引擎**：默认推荐，离线使用，无需模型下载。
- **通用多语模型**：用于其他离线语言，需要模型和足够内存。
- **在线 API**：填写服务地址、API Key 和模型，测试后保存。

本地失败不会自动发送原文到在线服务。在线翻译和连接测试可能产生服务用量。

关闭设置时可保存或放弃尚未提交的修改。

## 5. 研习与收藏

开启“英语研习”或“多语研习”后，可查看本地词典释义。

- 点击星标收藏单词。
- 英语单词支持英音、美音朗读。
- 主界面“单词收藏本”可筛选并随机复习至多 10 个收藏词。
- 多语词典可在设置或收藏本中安装。

## 6. 常用限制

- 选区最多 2,000 个 Unicode 码点，超限请缩短。
- 扫描图片 PDF 需先识别文字。
- VS Code 适配安装后需重新打开窗口；终端选词按 `Ctrl+Alt+Y`。
- 默认不保存翻译历史；卸载默认保留设置、密钥和收藏。
- 译文可能有误，重要内容请人工核对。
