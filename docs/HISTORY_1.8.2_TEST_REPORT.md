# 1.8.2 图标同步验证（2026-11-15）

本版只修改品牌图标及安装快捷方式的图标来源，应用行为沿用1.8.1。旧报告见 HISTORY_1.8.1_TEST_REPORT.md。

图标由 scripts/generate-brand.ps1 原生绘制，透明底、青紫渐变双层棱形边框、白色“译”字。ICO包含16、20、24、32、40、48、64、128、256九个尺寸；预览见 assets/yike-icon-preview.png。小尺寸省略部分装饰，保持字形辨识。

程序EXE、托盘内嵌资源与安装器共用assets/yike.ico；安装器将同一图标复制为安装目录YiKe-Prism.ico，桌面和开始菜单快捷方式明确引用该文件。更新时只通知外壳刷新对应快捷方式，不删除全局图标缓存或重启Explorer。

发布仍要求核心/界面/适配器、内置词库与NMT实际自检、源码/归档/文件哈希一致性检查。原有通用模型未改，重型Qwen专项通过显式参数标记本轮未重跑。安装和桌面快捷方式最终检查见开发工作目录 INSTALLED_1.8.2_RESULTS.json。

保留原配置、加密密钥、模型和快捷方式目标；当前构建仍未签名。
