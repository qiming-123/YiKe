# 译刻 · VS Code 划词适配

配合 Windows 译刻 1.0.2 及以后版本使用。无需开启 `editor.accessibilitySupport` 或读屏模式。

在译刻设置的“外观与行为”页点击“安装 / 更新 VS Code 适配”，或安装译刻时勾选 VS Code 适配任务。若当前 VS Code 窗口尚未激活新扩展，关闭并重新打开 VS Code。

仅在译刻确认鼠标拖选或双击后，经当前用户本机命名管道请求，读取当前焦点编辑器本次鼠标选区。只读取选区，最多 2,000 个 Unicode 码点，支持最多 32 个选区，以换行拼接。空选区、旧选区、键盘/命令选区变化、文件编辑或窗口切换后不返回旧文本。

不读取完整文件，不传递文件名、路径或编辑器内容到远程服务，不记录原文，不修改剪贴板或编辑器设置。译刻收到有效选区后，仍按你在译刻中配置的在线服务翻译。暂停、排除 Code、固定浮窗和取消规则继续生效。

扩展必须运行在本机 UI 扩展宿主；网页版不支持。本地普通文本/代码编辑器为本版验收范围。终端、网页预览、自定义编辑器、PDF 和远程工作区尚未验收，通过 UIA 支持程度另行判断。

在 VS Code 扩展页卸载 `yike-local.yike-selection` 即可移除此适配。卸载译刻不会移除 VS Code 中已安装的扩展，扩展在没有本机译刻请求时不会读取选区。
