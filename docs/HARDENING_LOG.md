# 1.0.1 持续检查记录

1.0.0 基线产物保留。追加工作围绕实际缺陷、异常边界与可重复验收展开，没有公开上传，没有使用私人服务凭据或开通付费服务。

主要改进：

- SessionState 区分取词有效期与网络序号；固定/解固定不复活旧任务，暂停保存失败也即时停用。
- 严格 UTF-8 SSE 限长：行 131072、事件 262144、流总计 2097152 个 UTF-16 单元；EOF 不派发未终止事件，stop 立即完成，空白/提前 DONE 报错。
- 配置、排除项和密钥控制字符校验；DPAPI 密文读取上限、明文字节清零；迁移密码与密钥验证。
- 设置导入刷新，保留合法非整数字号；测试可取消、不缓存、不保存，迟到反馈隔离。
- SelectionTransport 封装进程生命周期；逻辑超时、EOF 重置、父 PID/启动时间；释放失败不无限创建新进程。新增阻塞构造夹具发现 async 首次等待同步完成时仍会在调用线程启动进程，已用后台入口修正，失败用例转为通过。
- XAML 样式独立编译，正确下拉模板部件、可见键盘焦点、展开状态；系统偏好实时刷新。
- 实际桌面发现窗口空白，启用进程内软件渲染后恢复，未改系统设置。
- 浮窗自身 DPI 与工作区约束；设置/粘贴窗口随小屏、高缩放调整，侧栏可滚动；超长选区先通过鼠标位置核对。
- 鼠标手势仅接受配对的左键事件，右/中键取消旧坐标；双击采用单调时钟，排除拖选与其他来源窗口。
- 安装器正常退出、启动显式任务；真实旧版升级与文件占用故障恢复脚本。
- 发布构建记录、源码逐文件清单、归档路径安全及故意篡改拒绝测试。
