# 译刻 1.7.5 · 划词响应优化验收

2026-10-25（America/Denver，客户端日期）。本轮修复首次划选无反馈、重复划同文反复取消重启、第一段流式输出被刷新限速拦截的问题。此前文件操作过滤的资料见 HISTORY_1.7.4/TEST_REPORT.md。

## 行为变化

启动时只预热自有取词进程，不查询任何文字。默认松开鼠标后的等待从 250 ms 改为 80 ms。同一手势的空选区或暂未就绪接口可在 2.2 秒总预算内最多读取 6 次，仍使用原窗口、进程、坐标和取消租约，不读剪贴板或全文。明确的非文本、权限拒绝、超长及失效来源不重查。滚动条、标题栏等明确非文字控件改为终止状态，避免无意义等待。

较慢读取会在额外约 160 ms 后显示“正在读取选中文字”；约 240 ms 是设计等待值，受系统调度影响，不是所有电脑的测量保证。读取中不允许复制、重试或固定空白结果；读不到文字会提示。普通文字释放点稍超出窗口时按匹配的前台来源读取，仍核对窗口、进程和实际选区边界。

鼠标按下时旧浮窗立即隐藏，显示租约清零，旧结果不能覆盖读取卡片。已发送请求可短暂保留：同样文字、配置和凭据重新确认时复用进行中的请求并重放最新进度；不同文字确认后取消旧请求。普通单击会等待系统双击间隔（上限 1 秒），便于双击同文复用；明确非文本桌面按下、右键、显式关闭、暂停、排除和读取失败仍取消。拖选过程中隐藏的旧请求可能继续执行至确认新选区，已发送在线请求的计费无法撤回。

第一段有效译文到达即发布，后续约 80 ms 刷新；不再为了等待刷新周期而隐藏早到的首段。“重试”明确跳过缓存并发新请求。保留最多一项执行、一项可替换等待，未并行堆叠模型调用。所有计算机说明、语言、文件操作过滤、VS Code 与 WPS 通道保留。
